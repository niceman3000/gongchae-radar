## 3. 서비스 안에서 쓰는 AI (Anthropic Claude API)

| 하는 일 | 모델 | 언제 | 사람이 정한 안전장치 |
|---|---|---|---|
| 공고문에서 지원 자격·가점을 정해진 칸에 적기 | Claude Sonnet 5.5 (생각 끔) | 미리 한 번 (`tools/extract_requirements.py`) | 모든 칸에 쪽수+원문 인용, **코드가 원문에 실제로 있는지 대조**해 없는 인용·근거 없는 항목은 버림. 판정은 코드 |
| 그림·스캔 공고문 글자 옮겨 적기 | Claude Haiku 5.5 | 미리 한 번 (`tools/ocr_notices.py`) | 요약·해석 금지, 보이는 글자 그대로. 시험 조각을 사람이 원본과 대조. 화면에 "AI가 옮겨 적은 내용" 안내 |
| 사용자 질문 답변 | Claude Sonnet 5.5 (생각 끔) | 실시간 (질문 화면, 접속당 20회) | 코드가 고른 원문 조각 안에서만 답, 관련 원문이 없으면 AI를 부르지 않고 "공고문에 명시 없음", 답의 인용을 원문과 대조, "AI가 생성한 답변" 표시, 개인정보 질문 거절 |

- 작년 대비 비교, 같은 변경 묶기, 지원 가능·애매·불가 판정, 가점 계산은 **AI 없이 코드**
- AI 비용 (2026-11-20까지): 약 $7.3 (`evaluation/정확도_개선_기록.md` 7절)
- 사용자 입력(직렬·지역·자격증·질문)에 개인정보 칸이 없다. 이름·연락처 등을 받으면 오류

## 4. 개발에 쓴 AI 도구와 팀 역할

| 누가 | 한 일 |
|---|---|
| 팀 (사람) | 문제 정의·대상 사용자, 기능 범위와 우선순위 결정, AI 유료 사용·비용 승인, 화면·결과 확인과 지적(같은 뜻 표현, 묶어야 할 변경, 표현 수정 등), 실행·커밋, 정답지 검토(T012·T013 팀원), 발표 |
| Claude (Anthropic, 대화형 개발 도우미) | 코드 작성(수집·비교·판정·리포트·화면·질문·그림 옮기기·결과 PDF), 테스트, 규칙·기록 문서, 핵심 3곳 정답지 초안(원문 쪽수·인용 대조), 질문 평가표 초안 |
| Codex (OpenAI) | 같은 폴더에서 번갈아 코드·문서 작업 (`docs/worklog/WORKLOG_*.txt`에 날짜별 기록) |

- 정답지(`evaluation/ground_truth/`)와 질문 평가표는 **Claude가 원문을 대조해 작성**했고 팀원 검토는 진행 중이다 (사람이 썼다고 쓰지 않는다)
- AI가 만든 코드·문서는 테스트(`pytest`)와 화면 확인, 원문 대조로 검증했다

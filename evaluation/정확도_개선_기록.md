## 1. 전체 구조 (발표용 한 줄)

> 30곳 모두 **같은 자동 과정**(정부 API 수집 → 코드로 작년 대비 비교 → AI로 공고문의 지원 자격·가점 추출 → 코드로 판정)으로 만든다.
> 정확도를 재려고 3곳(한전·한수원·중부발전)은 **원문을 대조한 정답지**를 따로 두고 자동 결과를 채점한다.

| 단계 | 누가 | 정답지와 비교하는 지표 |
|---|---|---|
| 작년 대비 변경 찾기 | 코드 | 변경 후보 중 실제 변경 비율 (한전 원문 대조) |
| 지원 자격·가점 추출 | AI (Claude Sonnet 5.5) | 가점 재현율·정밀도, 지원 가능 자격증 재현율·정밀도 |
| 지원 가능·애매·불가 판정 | 코드 | 화면 판정 일치율 |

## 2. 지표 뜻

- **재현율**: 정답지 항목 중 자동 결과가 맞힌 비율 (빠뜨림이 적을수록 높음)
- **정밀도**: 자동 결과 항목 중 정답지와 맞는 비율 (지어내거나 틀린 게 적을수록 높음)
- **화면 판정 일치율**: 직렬 × (자격증 없음 + 자주 쓰는 자격증 39개 하나씩) 조건마다, 정답지로 판정한 결과와 자동 결과로 판정한 결과가 같은 비율.
  비교하는 것 = 지원 상태(지원 가능·애매·불가) + 받을 수 있는 최고 가점. 3곳 합계 600개 조건
- 가점·자격증 비교 단위 = (직렬, 자격증 이름, 점수). 종목×등급은 자격증 이름으로 펼쳐서 셈 (예: 전기 × 기사 → 전기기사)

## 3. 사람이 직접 확인할 때 챙긴 것 (정답지 만드는 기준)

정답지를 만들거나 자동 결과를 원문과 대조할 때 이 목록을 본다. (11-17~11-19 실제로 나온 사례)

**변경점 (작년 대비)**
1. 같은 뜻인데 표현만 바뀐 것은 변경이 아니다
   - 한수원 병역: "현역의 경우," → "병역대상자는" / 연령: "당사 규정은" → "당사 정년은" (사용자 지적, 11-18)
   - 2025/2026 사전평가 문구 (사용자 지적: "이것도 같은 의미")
2. 한 가지 변경이 여러 문장에 나뉘어 잡히면 하나로 본다 (사용자 지적: "두 개 합치면 같은 의민데")
   - 한수원 자기소개서: '폐지'가 아니라 '면접 대상자만 제출'로 시점이 바뀐 것 (PDF 6·12쪽)
3. 비슷해 보여도 다른 것은 따로 본다
   - 한수원 '체험형인턴 우수인턴'(신설, 필기 가점 5점) ≠ 기존 '경진대회 성적우수자' 가점 (PDF 7·8쪽)
4. API 표기 정규화를 실제 변경으로 믿지 않는다
   - 한전 근무지역 '광주·전남' → '전남광주': 원문은 두 해 모두 광주·전남 → 변경 아님 (PDF 2쪽)
5. 날짜만 해마다 바뀌는 것(어학성적 인정 기간 등)은 변경 카드가 아니라 '이번 공고 한눈에 보기'
6. 무엇이 바뀌었는지 제목에 구체적으로 (사용자 지적: "우대사항 세부 기준 변경… 이 항목이 의미하는 게 뭐냐")
7. 숫자는 쪽수와 원문 인용으로 확인 (한전 모집인원 421→490명, 서류 15배수→10배수, 면접 60·40→50·50 등)

**지원 자격·가점**
8. 직렬마다 지원 가능 전공과 '비전공자 지원 가능 자격증'을 따로 본다 (전공자 **또는** 자격증)
9. 가점표는 직렬별 표·등급별 점수(기사 10, 산업기사 5 등)·인정 종목을 빠짐없이
10. **대졸·고졸 점수표가 따로 있는지** 본다 (11-19 중부발전 25쪽 고졸 표를 처음 정답지에서 놓침)
11. 표 안의 긴 종목 목록을 끝까지 본다 (11-19 중부발전 23쪽 '비파괴검사' 6종을 처음 정답지에서 놓침)
12. 공통 가점(한국사·IT·외국어)과 직렬별 가점을 구분, 적용 제외 조건(예: IT 분야 지원자는 IT 가점 제외)
13. 가점 인정 규칙: 최대 몇 개, 같은 종류는 상위 등급만
14. 보훈·장애·사회형평·지역모집 같은 특별전형 모집단위는 판정에서 빼고 따로 안내
15. 가점 단위: 점 / % (예: 주택도시보증공사 '필기 배점의 0.3%')

해석
- 판정 일치(사용자가 실제로 보는 결과)는 96%. 가점 재현율이 75%인데도 판정이 높은 이유: 빠진 가점 상당수가 자주 쓰지 않는 자격증이거나, 같은 자격증의 다른 점수 행이라 '최고 가점'이 같게 나옴

## 6. 남은 한계 (솔직하게)

- 정답지는 3곳뿐이라, 22곳 AI 결과의 정확도는 직접 잰 값이 아니다 (3곳 결과로 추정)
- 22곳은 단계 4 지시문 **전**에 뽑았다 → 다시 뽑으면 한수원처럼 좋아질 가능성 (약 $3)
- 공고문이 그림·스캔인 7곳(공항공사·석유공사·인천공항·SR·강원랜드·한전KDN, 마사회 표)은 지원 자격 자동 추출 없음 → 애매

- 정답지 자체도 틀릴 수 있다 (중부발전 사례). 정답지에 없는 AI 항목은 원문으로 확인한 뒤 판단
